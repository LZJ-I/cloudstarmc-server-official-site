# 云星 Minecraft 服务器官方网站

云星 Minecraft 服务器官方网站源码仓库，包含首页、百科、事件时间线、加入指南、团队展示，以及可直接维护站点内容的管理后台。

## 项目概览

这个项目不是单纯的静态展示页，而是一套面向服务器官网运营的站点系统，主要包含以下部分：

- 官网首页与视觉展示
- 百科系统（about、分类、子页面）
- 事件时间线页面
- 加入指南页面
- 团队 / 成员展示页面
- 管理后台（用于编辑百科、事件、特色、加入指南、成员、站点资源等内容）

## 主要目录结构

```text
.
├─ web/                       前端静态资源与内容目录
│  ├─ index.html              站点入口
│  ├─ partials/               首页、百科等页面片段
│  ├─ css/                    样式文件
│  ├─ js/                     前端路由与交互逻辑
│  ├─ wiki/                   百科内容、索引与页面文件
│  ├─ events/                 事件时间线数据
│  ├─ features/               首页特色模块数据
│  ├─ join-guide/             加入指南数据
│  ├─ staff/                  成员展示数据与资源
│  └─ admin/                  管理后台页面与脚本
├─ server.mjs                 站点服务入口
├─ admin-routes.mjs           管理后台相关接口
├─ wiki-build.mjs             百科构建脚本
├─ package.json               项目依赖与脚本
└─ 依赖与部署.md             部署与运行说明
```

## 功能特性

### 1. 官网前台

- 支持首页展示、视觉动效与品牌内容呈现
- 支持百科浏览、分类导航与正文目录
- 支持事件时间线展示
- 支持加入指南与成员展示

### 2. 百科系统

- 已从传统单页内容演进为 `about + 分类 / 子页面` 结构
- 支持单独页面文件管理
- 支持目录、分类、页面排序与内容维护

### 3. 管理后台

管理后台支持对以下内容进行直接编辑：

- 百科
- 首页特色模块
- 加入指南
- 事件时间线
- 团队成员
- 管理员账号
- 站点资源图

## 本地运行

先安装依赖：

```bash
npm install
```

启动项目：

```bash
npm start
```

如果仓库脚本或环境有调整，请以实际 `package.json` 和 `依赖与部署.md` 为准。

## 内容数据位置

常见可编辑内容默认位于以下目录：

- 百科：`web/wiki/`
- 事件：`web/events/events.json`
- 首页特色：`web/features/features.json`
- 加入指南：`web/join-guide/join-guide.json`
- 成员资料：`web/staff/`

## 适用场景

这个仓库适合以下用途：

- Minecraft 服务器官网展示
- 社区内容沉淀与百科维护
- 通过后台进行日常运营更新
- 作为中小型内容站 / 游戏社区官网模板进行二次开发
