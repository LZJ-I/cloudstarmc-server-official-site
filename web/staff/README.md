# 团队展示怎么配

这里管官网上的**成员名单与介绍**。每个人一个文件夹，里面放 **`meta.json`**，页面上**怎么称呼这位成员只看 `name`**；不写或留空时显示 **「示例」**。

## 怎么配

1. **新加一个人**：复制 **`_template`**，文件夹名**建议英文/数字/下划线**（别用 `_` 开头）。在同目录放好头像图，**默认文件名**是 **`head.png`**（小头像）和 **`portrait.png`**（大图），也可以在 **`meta.json`** 里用 `headFile`、`portraitFile` 改成别的文件名。最后改好 **`meta.json`**。
2. **改信息 / 换图**：改 `meta.json`；换图时要么覆盖默认文件名，要么改 `headFile` / `portraitFile` 与磁盘上一致，并**强刷页面**。

**图加载失败时**：会依次回退为 **`_template/head.png`**、**`_template/portrait.png`** 等，最终以 **`web/staff/_template/head.png`** 为止，不再用其它目录的图片。

## `meta.json` 里能填什么

| 字段 | 填什么 |
|------|--------|
| `order` | 数字，**越小越靠左**。不写则靠后，同档按文件夹名。 |
| `name` | **页面上显示的名字**；不写、留空或删掉本行，显示为 **「示例」**。 |
| `title` | 一句话职位或标签。 |
| `bio` | 个人介绍，支持多行/换行。 |
| `color` | **团队区左侧**当前成员里，**大号「名字」**用的**文字颜色**（`#` + 六位十六进制，如 `#EA323C`）。`title` 小标签是固定灰字，**不吃这个色**。不写或格式错时，用页面默认红。 |
| `headFile` | **小头像**的**文件名**，图必须放在**该成员自己的子文件夹**里（`web/staff/该成员文件夹/`），**不能写路径、不能出本目录**；默认 **`head.png`**。 |
| `portraitFile` | **大图/立绘**的**文件名**，**同样只能放在该成员子文件夹里**。 |

更细的键说明见 **`web/staff.meta.example.json`**，示例见 **`_template/meta.json`**。
