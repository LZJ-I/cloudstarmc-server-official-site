# 事件时间线怎么配

时间线数据在 **`web/events/events.json`**。接口 **`GET /api/events`** 与前台页面读取同一份；无 Node 时可请求静态 **`/events/events.json`**（若部署时暴露了该目录）。

## JSON 结构

```json
{
  "section": { "title": "", "subtitle": "" },
  "items": [
    {
      "id": "evt-…",
      "date": "2026-04-24 15:36",
      "title": "",
      "body": "",
      "tier": "minor"
    }
  ]
}
```

## 字段说明

| 字段 | 填什么 |
|------|--------|
| `section.title` / `section.subtitle` | 时间线区块的**主标题**、**副标题**（页眉）。 |
| `items[].id` | 唯一 id；后台新增会自动生成 **`evt-` + 十六进制**，一般不用手改。 |
| `items[].date` | 显示日期；可为 `YYYY-MM-DD` 或带时间，按字符串展示。 |
| `items[].title` | 本条标题。 |
| `items[].body` | 本条正文（多行纯文本/Markdown 视前台渲染而定，当前多为纯文本段落）。 |
| `items[].tier` | **`major`**（大事件）或 **`minor`**（小事件）；其它值会按小事件处理。 |

## 在管理后台里怎么改（`/admin/` → 事件）

1. 左侧按 **年份** 点标题浏览；右侧用 **索引** 下拉选 **页眉** 或某年某月某条。
2. **页眉** 编辑整块区的 `section` 标题、副标题。
3. 每条事件可改 **日期、标题、正文、大/小事件**；**添加事件** 追加到列表。
4. **保存** 写入 `events.json`；**从服务端重新加载** 放弃未保存修改。
