# 什么是 Markdown

**Markdown** 是一种轻量标记语言，目标是用易读、易写的纯文本写出可转为 HTML 的结构。概念最初由 *John Gruber* 在 2004 年提出，后衍生出 CommonMark 等更严格的规范实现。

> 对百科来说：首行一级标题会出现在侧栏，正文支持标题、列表、代码块等，便于写规则与说明。

## 和 HTML 的关系

- 先写 `.md` 再渲染成页面，是文档站、Wiki 的常用方式。
- 需要复杂布局时，仍可在正文中内嵌受允许的 HTML 片段（视站点策略而定）。
